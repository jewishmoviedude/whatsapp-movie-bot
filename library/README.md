# Clean-title catalogue

`clean-titles.md` and `clean-titles.json` list every film on the server that
carries a rating the bot is allowed to send. They are generated by the
"Rebuild the list" button in the portal (Settings → System → Clean-title
catalogue), which walks the whole Jellyfin library.

Kept in the repo deliberately: it is a plain reference list, and having it
versioned shows what changed between rebuilds.

**Titles only.** No filesystem paths, no Jellyfin item ids, no server address
and no token — the scan asks Jellyfin for names, years and ratings and keeps
nothing else, because these files leave the machine.

Unrated titles are **not** listed. An unrated file is one nobody has checked,
and this list is used to decide what may be sent, so the omission is
deliberate rather than a gap.

**A rebuild reads the whole library or publishes nothing.** Jellyfin serves at
most 10,000 results per query, and the list built on 2026-09-09 stopped there:
10,000 of the server's 20,796 films, ending at "The Jurassic Games", with no
warning. The walk now continues past that window from the sort name it reached,
and compares the films it read against the count the server reports. A walk
that falls short is refused: the previous list is kept, the panel says how far
the rebuild got, and the audit log records it. So is a walk whose size the
server would not report, and - unless an admin rebuilds again with "publish
anyway" - one whose list is more than 10% shorter than the published one, which
is what a briefly unmounted or inaccessible library looks like. The rebuild
runs in the background (a full walk is over a minute) and the panel shows its
progress. The file's header and the JSON both record how many of the server's
films the walk read.

**Unrated means the bot's definition of unrated.** No rating, NR, Not Rated,
Unrated and N/A are all left out and counted as unrated, as the header says.
The list built on 2026-09-09 counted only an empty rating, and carried 1,490
NR / Not Rated / Unrated titles under a header saying unrated titles were not
listed. While "block unrated" is off, the bot itself still sends such films;
the header says so.
